# StorageUnit Management System - Frontend

**SOA Final Examination Project** | Student ID: `2400033056` | Project: `CrudServiceProject`

A clean, responsive Single Page Application (SPA) built for managing Storage Units in the Spring Boot `CrudServiceProject` using **React Router DOM**, **React Context API**, **Axios**, **Fetch**, and **Bootstrap 5**.

---

## 🌐 Independent URL Routes (React Router DOM)

The frontend uses `react-router-dom` to provide independent URL endpoints for all CRUD activities:

| URL Route | Component / Page | Description |
| :--- | :--- | :--- |
| **`/viewall`** | [`ViewAllPage.jsx`](./src/pages/ViewAllPage.jsx) | Displays all records in a responsive table with ID, Unit Code, Size, Fee, Status, and Delete action. |
| **`/add`** | [`AddPage.jsx`](./src/pages/AddPage.jsx) | Dedicated form to add a new storage unit. **Strictly contains NO ID input field** (auto-generated by DB). |
| **`/`** | Redirect | Automatically redirects to `/viewall`. |

---

## 🚀 Key Features & Requirements Compliance

1. **Independent Pages with React Router DOM**:
   - Clean URLs: `/viewall` and `/add` using `<BrowserRouter>`, `<Routes>`, `<Route>`, `<Link>`, and `<NavLink>`.
2. **Clean Minimal Navigation Bar**:
   - Contains only the brand (`Storage Unit CRUD`) and the direct CRUD activity buttons (`/viewall` and `+ /add`).
3. **React Context API**:
   - Implemented in [`src/context/StorageUnitContext.jsx`](./src/context/StorageUnitContext.jsx).
   - Manages records state, loading states, and feedback alerts across all routes.
4. **Dual HTTP Network Layer (Axios & Fetch)**:
   - Implemented in [`src/api/storageUnitApi.js`](./src/api/storageUnitApi.js).
   - Uses native **Fetch API** for `GET /storageunit/displayall`.
   - Uses **Axios** for `POST /storageunit/add` and `DELETE /storageunit/delete/{id}`.
5. **No ID Field in Add Form**:
   - The Add form does not have an ID input field. The ID is generated automatically by PostgreSQL (`@GeneratedValue(strategy = GenerationType.IDENTITY)`).
6. **Frontend Validation**:
   - Unit Code (required, 2-20 characters).
   - Size (required, positive number > 0).
   - Monthly Fee (required, positive number > 0).
   - Clear inline feedback and error messages.
7. **Delete Action with Confirmation Modal**:
   - Modal confirmation before executing `DELETE /storageunit/delete/{id}`.

## 💻 Running the Application

### 1. Prerequisites
- Spring Boot backend running on `http://localhost:8081`

### 2. Run Frontend
```bash
cd crudservice-frontend
npm install
npm run dev
```
Open **http://localhost:3000/viewall** in your browser.
